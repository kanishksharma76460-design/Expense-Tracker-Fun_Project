# Expense-Tracker-Fun_Project
 Advanced Expense Tracker CLI App built with Python. Allows users to add, view, and delete expenses with category-wise analysis. Implements file handling for persistent storage, structured data management, and error handling. Demonstrates real-world financial tracking logic in a CLI environment.


Overview::

A command-line based Expense Tracker built using Python. This application allows users to record, manage, and analyze their daily expenses efficiently with persistent storage support.

Features::
Add expenses with title, amount, and category
View all recorded expenses
Delete expenses using unique ID
Category-wise spending analysis
Persistent storage using

Concepts Used::
Dictionaries & Data Structuring
Functions (Modular Programming)
Loops (Continuous Execution)
File Handling (Read/Write)
Exception Handling (Input Validation)
